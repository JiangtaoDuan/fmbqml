fmbqml documentation
====================

``fmbqml`` is a Python package for testing and estimating structural breaks
in high-dimensional factor models using quasi-maximum likelihood (QML)
methods. It provides single-break LR testing, direct breakpoint estimation,
joint multiple-break estimation, joint sup-LR testing, and singular-versus-
rotational break classification.
